## 🚀 KẾ HOẠCH TRIỂN KHAI

### PHASE 1: TECHNICAL SEO (Tuần 1-2)

#### 1.1 Cải thiện Sitemap
- [ ] Thêm tất cả products vào sitemap
- [ ] Thêm categories và brands vào sitemap
- [ ] Tạo sitemap index nếu cần
- [ ] Thêm lastModified từ database
- [ ] Priority và changeFrequency hợp lý

#### 1.2 Structured Data (Schema.org)
- [ ] **Product Schema** cho mỗi laptop
  - Name, description, image
  - Price, availability
  - Brand, category
  - AggregateRating (nếu có reviews)
- [ ] **BreadcrumbList** cho navigation
- [ ] **Review/Rating** schema
- [ ] **FAQPage** cho các trang dịch vụ
- [ ] **Service** schema cho dịch vụ
- [ ] **Organization** schema cải thiện
- [ ] **WebSite** schema với SearchAction

#### 1.3 Robots.txt
- [ ] Kiểm tra và tối ưu
- [ ] Thêm sitemap location
- [ ] Block admin pages

#### 1.4 Performance
- [ ] Image optimization (WebP, lazy loading)
- [ ] Minify CSS/JS
- [ ] Enable compression
- [ ] CDN setup
- [ ] Core Web Vitals optimization

### PHASE 2: ON-PAGE SEO (Tuần 3-4)

#### 2.1 Title Tags Optimization
- [ ] Homepage: "Laptop Cần Thơ | Mua Bán Laptop Cũ Mới Chính Hãng Giá Tốt"

- [ ] Category pages: "{Danh mục} Laptop Cần Thơ | Giá Tốt Nhất"

#### 2.5 Internal Linking
